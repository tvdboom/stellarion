# Asset sources

## Space-fauna audio

The space-fauna firing sounds are selected from **80 CC0 creature SFX** by
rubberduck, dedicated to the public domain under CC0:
https://opengameart.org/content/80-cc0-creature-sfx

| Runtime source | Pack source |
| --- | --- |
| `assets/audio/fauna electric.ogg` | `alien/alien_01.ogg` |
| `assets/audio/fauna pulse.ogg` | `weird/weird_03.ogg` |
| `assets/audio/fauna acid.ogg` | `spit/spit_02.ogg` |
| `assets/audio/fauna roar.ogg` | `monster/monster_01.ogg` |
| `assets/audio/fauna dragon.ogg` | `roar/roar_02.ogg` |

The filenames were changed to provide stable in-game asset keys. CC0 does not
require attribution; this record is retained as source provenance.
